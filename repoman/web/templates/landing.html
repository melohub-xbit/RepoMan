How it works
  1. IntakeGitHub URL or zip, a report PDF, a deployed URL.
  2. CompileThe rubric becomes a checklist you approve. "Creativity" stays with you.
  3. ProbeDependencies, tests, git history, injection, liveness — computed, not guessed.
  4. VerifyAn agent searches the checkout per requirement and cites what it finds.
  5. DecideYou read, open the evidence, and enter the marks.

Same code on a laptop with a local model — nothing leaves the machine — or on AWS for the whole cohort from one URL.

RepoMan does not judge people's work. It does the investigation a human needs before they can.
