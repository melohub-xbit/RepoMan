Five stages. Four are RepoMan's. The last one is yours.

  1. IntakeA GitHub URL or zip, a report PDF, a deployed URL. The repository is pinned to its commit.
  2. CompileYour rubric becomes a checklist you approve. Lines like "creativity" stay with you and never reach a model.
  3. ProbeDependencies, tests, git history, prompt injection, liveness. Computed, not guessed.
  4. VerifyAn agent searches the checkout per requirement and cites the exact lines. Every citation is re-read before it is shown.
  5. DecideYou read the finding, open the evidence in place, and enter the marks. RepoMan never totals.

Verified, not trusted

Every citation is re-read at the pinned commit before it is shown. One that does not resolve is dropped, never rendered.

Contradictions surface

Only cross-checking the report against the code produces this, and it is the finding that matters most.

The report saysfull RBAC across five user tiers
The code showsenum UserRole { ADMIN, USER }

"Found nothing" is an answer

Unverified is not "not implemented". The finding lists where it looked, so you can check in twenty seconds.

Flagged

Hostile input, flagged

Prompt injection, deadline-hour code dumps, one-author teams: caught by deterministic probes and shown with their location.

Your marks, your precedent

Accept or override each finding. An override becomes a precedent for the rest of the batch, so every submission is held to the same standard.

RepoMan does not judge people's work. It does the investigation a human needs before they can.
