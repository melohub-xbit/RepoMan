# TaskFlow — Backend Project Rubric

Total: 100 marks.

1. **Authentication — 20 marks.** The application issues a JWT on login and validates it on
   protected routes.

2. **Role-based authorization — 20 marks.** Distinct user roles are defined and enforced on
   the endpoints that need them.

3. **Caching layer — 10 marks.** A caching layer is configured and used by the application.

4. **Automated tests — 20 marks.** Graded in bands: *none* (0), *some tests present* (10),
   *meaningful coverage with real assertions* (20).

5. **Code quality — 15 marks.** The code is organised into clear layers rather than one file.

6. **Creativity and originality — 15 marks.** How imaginative the project is.
